# How to publish

1. Open `index.html` and replace:
   - YOUR_EMAIL@osu.edu
   - YOUR_LINKEDIN_URL
   - YOUR_DUET_PAPER_URL
   - YOUR_ICML_PAPER_URL
   - YOUR_GRAD_DATE

2. Put your CV in this folder and name it `cv.pdf`.

3. On GitHub, create a public repository named exactly:
   `YOUR_GITHUB_USERNAME.github.io`

4. Upload `index.html`, `style.css`, `profile.jpg`, and `cv.pdf` to the repository.

5. Commit the files. Your page will appear at:
   `https://YOUR_GITHUB_USERNAME.github.io/`
